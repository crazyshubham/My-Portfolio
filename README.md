---

## 🌐 Deploy on GitHub Pages

1. Go to your repo → **Settings** → **Pages**
2. Under **Source** → select `main` branch → `/ (root)`
3. Click **Save**
4. Your site will be live at `https://crazyshubham.github.io/My-Portfolio`
