InsightScan — NLP Article Intelligence Pipeline

Python NLP NLTK BeautifulSoup pandas Data Pipeline

A fully automated 4-stage NLP data pipeline that scrapes, analyzes, and scores 82 web articles across 15 metrics — with zero manual steps. The pipeline covers web scraping (requests + BeautifulSoup), sentiment analysis using the Loughran-McDonald lexicon (polarity, subjectivity), and readability scoring (Gunning Fog Index, syllable counts, personal pronoun detection) — all exported to a clean Output.xlsx. Results: avg polarity +0.41, avg Fog Index 14.2, 61% of articles classified as positive sentiment.
